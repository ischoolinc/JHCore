# 匯入學生基本資料調整 0810

## 調整目的

調整學生基本資料匯入「欄位選擇頁」之不完整群組提示內容。

當 Excel 群組欄位不完整時，原本 Tooltip 只列出**缺漏**欄位；改為列出該 BulkDescription 群組的**完整必要欄位清單**，讓使用者一次看懂此群組應具備的完整格式。

## 原始行為

`ImportItem.CheckAccept(BulkColumnCollection basis)` 以 `missingFields` 收集 Excel 缺少的欄位，並在 Tooltip 中只顯示那些缺漏欄位。

文案：

```text
Excel「監護人」群組欄位不完整。
若要匯入此資料，Excel 尚需包含：

監護人:學歷
監護人:職業
```

（已存在於 Excel 的 `監護人:電話` 不會出現在提示中。）

## 新行為

完整性判斷規則不變：只要 BulkDescription 群組中任一欄位不在 Excel 來源中，即視為不完整。

一旦判定不完整，Tooltip 改為列出 `basis.Values` 的**全部**欄位（經家長別名顯示轉換）。

文案：

```text
Excel「監護人」群組欄位不完整。
若要匯入此資料，Excel 必須包含完整欄位：

監護人:學歷
監護人:職業
監護人:電話
```

完整群組：`Enabled = true`，不顯示不完整提示，可正常勾選。

## 修改方法

### `ImportItem.CheckAccept(BulkColumnCollection basis)`

兩段式處理：

1. 掃描 `basis.Values`，若任一欄位不在 `SheetColumns` → `hasMissingField = true`
2. 若不完整：
   - `Enabled = false`、`Checked = false`
   - Tooltip 文案改為「必須包含完整欄位」
   - 再次遍歷 `basis.Values`，以 `GetParentAliasDisplayText` 列出完整群組欄位

## 為何未改動群組完整性規則本身

本次僅調整「不完整時要顯示什麼」。

停用條件仍為：

> BulkDescription 群組中至少有一個欄位不存在於 Excel 來源

完整群組仍可勾選；不會對每個群組一律顯示警告。

群組認定仍依 `DisplayColumns()` 既有邏輯，以 `Context.BulkDescription.Columns`（`Count > 1`）為準，不以 Excel 欄位數或 `IsGroupColumn` 回頭判斷。

## 完整群組欄位清單如何動態產生

清單來源固定為參數 `basis`（`BulkColumnCollection`），來自：

```text
Context.BulkDescription.Columns
  → DisplayColumns() 依 InternalGroupName 取得 groupColumns
  → each.CheckAccept(groupColumns)
```

未硬編碼監護人／前級／戶籍／聯絡／家長1／家長2／其它電話或其子欄位清單。

## 家長別名顯示處理

內部比對仍使用正規化後名稱（`父親`／`母親`）。

顯示時繼續透過：

```csharp
GetParentAliasDisplayText(each.FullDisplayText)
GetParentAliasDisplayText(InternalGroupName)
```

因此不完整 `父親`／`母親` 群組對使用者顯示為：

```text
Excel「家長1」群組欄位不完整。
若要匯入此資料，Excel 必須包含完整欄位：

家長1:學歷
家長1:職業
家長1:電話
```

```text
Excel「家長2」群組欄位不完整。
若要匯入此資料，Excel 必須包含完整欄位：

家長2:學歷
家長2:職業
家長2:電話
```

不會對使用者顯示內部名稱「父親／母親」。
