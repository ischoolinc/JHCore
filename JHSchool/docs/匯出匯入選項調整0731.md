# 匯出／匯入選項無法多選問題調整紀錄（0731）

## 問題描述

學生基本資料「匯出／匯入」精靈的欄位清單，無法以滑鼠進行多選：

- 滑鼠拖曳選取多個項目
- `Ctrl` 點選不連續項目
- `Shift` 點選連續範圍

使用者無法依一般 ListView 操作方式選取多個欄位。

## 根因

先前為消除藍色底色，在 `ConfigureFieldListView()` 中註冊了 `ItemSelectionChanged`，並在選取時立刻將 `Selected` 設回 `false`：

```csharp
private void FieldListView_ItemSelectionChanged(
    object sender,
    ListViewItemSelectionChangedEventArgs e)
{
    if (e.IsSelected)
        e.Item.Selected = false;
}
```

此作法會立刻清掉選取狀態，導致拖曳、`Ctrl`、`Shift` 多選皆無法運作。

此問題同時存在於：

- 匯出欄位清單：`listView`
- 匯入欄位清單：`lvSourceFieldList`

補充：欄位清單已改為標準 WinForms `ListView`（不再使用 `ListViewEX`），因此不再需要以清除選取來壓抑自訂繪製造成的藍底；`Selected` 高亮屬於正常選取回饋。

## 修改檔案

| 檔案 | 說明 |
| --- | --- |
| `StudentExtendControls/Ribbon/StudentExportWizard.cs` | 調整 `ConfigureFieldListView()`；移除 `FieldListView_ItemSelectionChanged` |
| `StudentExtendControls/Ribbon/StudentImportWizard.cs` | 調整 `ConfigureFieldListView()`；移除 `FieldListView_ItemSelectionChanged` |

Designer 檔案未修改版面；`HideSelection` 等屬性由 runtime 的 `ConfigureFieldListView()` 覆寫即可。

## 修改方法

### `StudentExportWizard.ConfigureFieldListView`

```csharp
private void ConfigureFieldListView()
{
    listView.MultiSelect = true;
    listView.HideSelection = false;
    listView.BackColor = SystemColors.Window;
    listView.BorderStyle = BorderStyle.FixedSingle;
}
```

### `StudentImportWizard.ConfigureFieldListView`

```csharp
private void ConfigureFieldListView()
{
    lvSourceFieldList.MultiSelect = true;
    lvSourceFieldList.HideSelection = false;
    lvSourceFieldList.BackColor = SystemColors.Window;
    lvSourceFieldList.BorderStyle = BorderStyle.FixedSingle;
}
```

兩處皆已移除 `FieldListView_ItemSelectionChanged` 事件註冊與對應處理方法（無其他引用）。

## 變更前後行為

| 項目 | 變更前 | 變更後 |
| --- | --- | --- |
| 滑鼠拖曳多選 | 無法保留選取 | 可選取多個項目 |
| `Ctrl` 多選 | 無法運作 | 可選取不連續項目 |
| `Shift` 範圍選取 | 無法運作 | 可選取連續範圍 |
| 選取高亮可見性 | 立刻清除；`HideSelection = true` | 保留選取高亮；`HideSelection = false` |
| `MultiSelect` | 未明確設定 | 明確設為 `true` |
| Checkbox 勾選狀態 | 依 `Checked` / `ItemCheck` | 不變；選取不會自動勾選／取消勾選 |
| 全選／全部選取 | 依既有邏輯 | 不變 |
| 匯入停用／唯讀／必填鎖定 | `lvSourceFieldList_ItemCheck` 等既有規則 | 不變 |
| 匯出／匯入資料邏輯、XML、家長欄位對應、精靈導覽、驗證 | 不變 | 不變 |

## Selected 與 Checked 的區別

| 狀態 | 意義 | 用途 |
| --- | --- | --- |
| `Selected` | 項目被選取／高亮 | 僅 UI 選取範圍；多選操作作用於此狀態 |
| `Checked` | 核取方塊勾選 | 實際決定匯出／匯入要處理哪些欄位 |

本次修正只恢復 `Selected` 的多選能力，**不會**因選取而自動變更 `Checked`。匯出／匯入仍只依勾選（`Checked`）欄位處理，而非僅依選取（`Selected`）欄位。

## 匯出／匯入資料邏輯確認

以下皆未修改：

- 匯出／匯入實際欄位讀寫與檔案輸出格式
- 家長欄位對應（畫面「家長1／家長2」與內部「父親／母親」）
- XML 欄位名稱與結構
- 必填欄位紅字／停用欄位灰字
- 精靈頁面導覽與驗證邏輯
- 匯入 `lvSourceFieldList_ItemCheck` 對停用、唯讀、必填鎖定欄位的限制
- 「全選／全部選取」既有行為
