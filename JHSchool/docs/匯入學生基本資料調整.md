# 匯入學生基本資料 — 家長欄位別名調整紀錄

## 問題描述

匯出學生基本資料後，Excel 欄位標題已改為：

- `家長1姓名`、`家長2姓名`
- `家長1:學歷`、`家長1:職業`、`家長1:電話`
- `家長2:學歷`、`家長2:職業`、`家長2:電話`

但匯入規格（`JH_S_BulkDescription`）與內部 XML 產生邏輯仍使用：

- `父親姓名`、`母親姓名`
- `父親:學歷`、`母親:學歷` 等

若不做別名轉換，Excel 的 `家長1`／`家長2` 欄位會被視為不支援欄位，無法選取與匯入。

## 目標

在**不修改** `JH_S_BulkDescription`、不改變父親／母親 XML 結構的前提下，讓 Excel 可使用 `家長1`／`家長2` 標題，內部仍對應既有 `父親`／`母親` 欄位定義。

## 修改檔案

| 檔案 | 說明 |
| --- | --- |
| `StudentExtendControls/Ribbon/StudentImportWizardControls/SheetModel/SheetColumn.cs` | 新增 `SourceName`／`DisplayText`，並以 `SetInternalName()` 寫入內部欄位名稱 |
| `StudentExtendControls/Ribbon/StudentImportWizardControls/SheetModel/SheetReader.cs` | 新增 `NormalizeParentImportFieldName()`、`NormalizeParentImportFieldNames()` |
| `StudentExtendControls/Ribbon/StudentImportWizardControls/WizardContext.cs` | 在 `RefreshImportSource()` 於 `BindSheet` 後立即執行別名正規化 |
| `StudentExtendControls/Ribbon/StudentImportWizard.cs` | 欄位選擇 UI 顯示 Excel 原始標題；比對仍使用內部名稱 |

未修改：

- `JH_S_BulkDescription` / `JH_S_BulkDescription.xml`
- `GenerateInsertRequest()` / `GenerateUpdateRequest()`
- 資料庫欄位名稱、服務請求元素名稱
- 其他非家長相關匯入邏輯

## 修改的類別與方法

### `SheetColumn`

- `SourceName`：保留 Excel 原始標題（用於 UI 顯示）
- `Name`：內部匯入欄位名稱（用於 BulkDescription、驗證、產生 XML）
- `DisplayText`：回傳 `SourceName`
- `SetInternalName(string)`：寫入正規化後的內部名稱並更新群組資訊

### `SheetReader`

- `NormalizeParentImportFieldName(string)`：集中別名轉換
- `NormalizeParentImportFieldNames()`：重建以內部名稱為 key 的欄位集合

### `WizardContext`

- `RefreshImportSource()`：每次重新載入 Excel 後呼叫 `NormalizeParentImportFieldNames()`

### `StudentImportWizard`

- `GetImportDisplayName(SheetColumn)`：UI 顯示 Excel 別名
- `ImportItem`：新增 `InternalGroupName`／`InternalFieldName`，顯示與比對分離
- `DisplayColumns`／`GroupSheetColumn`：改以內部名稱做 AcceptColumns／群組比對

## 別名轉換實作位置

轉換發生在資料流最早且每次都會經過的位置：

```text
RefreshImportSource()
  → SheetReader.BindSheet()
  → SheetReader.NormalizeParentImportFieldNames()
  → AcceptColumns 交集比對
  → 驗證 / GenerateInsertRequest / GenerateUpdateRequest
```

`StudentImportWizard` 會在選檔、驗證前、正式匯入前多次呼叫 `RefreshImportSource()`，因此別名轉換每次都會重新套用。

## 原始 Excel 標題如何保留

- `SheetColumn.SourceName` / `DisplayText` = Excel 原始標題（如 `家長1姓名`）
- 讀取儲存格仍以 `AbsoluteIndex` 為準，不依賴標題字串定位實體欄位

## 內部欄位名稱如何使用

- `SheetColumn.Name` = 正規化後內部名稱（如 `父親姓名`）
- `SheetColumnCollection` 的 dictionary key 使用內部名稱
- `AcceptColumns`、`SelectedFields`、`ValidateColumns`、`GetColumnList`、`GenerateInsertRequest`／`GenerateUpdateRequest` 全部使用內部名稱

## 限制與注意事項

1. 同一份 Excel **不可同時**出現會正規化成相同內部名稱的欄位（例如同時有 `家長1姓名` 與 `父親姓名`），否則會觸發「重覆的欄位名稱」錯誤。
2. 複合欄位實際 Excel 標題格式為 `家長1:學歷`（與匯出端一致），而非 `家長1其它資訊:學歷`；前綴轉換兩者皆可處理，但 BulkDescription 比對的是 `父親:學歷`。
3. 未修改 XML 資源；若未來要讓規格檔本身改用家長用語，需另開需求評估。

## 驗證欄／識別欄下拉選單 UI 別名調整（2026-07-17）

### 問題描述

更新匯入模式中，「識別欄」與「驗證欄」下拉選單直接綁定 `BulkColumn.DisplayText`，因此仍顯示 `父親姓名`、`母親姓名` 等內部用語。先前 `GetImportDisplayName()` 僅影響欄位選擇 `ListView`，未涵蓋 `cboIdField`／`cboValidateField`。

### 目標

僅變更下拉選單的**顯示文字**；`Context.IdentifyField`、`Context.ShiftCheckField` 及後續驗證、Shift Check、XML 產生邏輯仍使用原始內部欄位名稱（`父親*`／`母親*`）。

### 修改檔案

| 檔案 | 說明 |
| --- | --- |
| `StudentExtendControls/Ribbon/StudentImportWizard.cs` | 新增 UI 別名方法、包裝類別，並調整識別欄／驗證欄下拉選單的填入與選取處理 |

未修改：

- `JH_S_BulkDescription` / `JH_S_BulkDescription.xml`
- `BulkColumn.DisplayText` 與 `Context.AcceptColumns`
- `GenerateInsertRequest()` / `GenerateUpdateRequest()`
- `ShiftCheckList`、驗證規則、資料庫查詢邏輯

### 修改的類別與方法

#### `GetParentAliasDisplayText(string)`

將 `BulkColumn.DisplayText` 轉為下拉選單顯示用語，規則：

```text
父親* → 家長1*
母親* → 家長2*
```

不修改原始 `BulkColumn` 物件。

#### `BulkColumnOption`（private class）

包裝下拉選項，分離 UI 顯示與內部欄位：

| 屬性 | 內容 |
| --- | --- |
| `DisplayText` | UI 別名（如 `家長1姓名`） |
| `Column` | 原始 `BulkColumn`（`Column.DisplayText` 仍為 `父親姓名`） |

#### `wpCollectKeyInfo_AfterPageDisplayed`

- 驗證欄空選項改以 `BulkColumnOption` 包裝 `Context.EmptyShiftCheckField`（顯示文字維持 `<不使用>`）
- 識別欄／驗證欄改加入 `BulkColumnOption`，不再直接加入 `BulkColumn`

#### `wpCollectKeyInfo_NextButtonClick`

- 由 `BulkColumnOption.Column.DisplayText` 寫入 `Context.IdentifyField`
- 由 `BulkColumnOption.Column.DisplayText` 寫入 `Context.ShiftCheckField`；選取空選項時明確設為 `string.Empty`

### 驗證欄下拉選單值的原始來源

```text
Context.AcceptColumns.Values（BulkColumn）
  → 篩選 ShiftCheckable == true
  → GetParentAliasDisplayText(each.DisplayText)
  → BulkColumnOption
  → cboValidateField
```

識別欄同理，篩選條件為 `Identifiable == true`。依 `JH_S_BulkDescription.xml`，家長相關可驗證欄位為：

- `父親姓名`、`父親身分證號`、`父親國籍`、`父親存歿`
- `母親姓名`、`母親身分證號`、`母親國籍`、`母親存歿`

### 資料流

```text
BulkColumn.DisplayText = 父親姓名
        ↓
GetParentAliasDisplayText()
        ↓
BulkColumnOption.DisplayText = 家長1姓名
        ↓
ComboBox 顯示 家長1姓名
        ↓
使用者選取
        ↓
BulkColumnOption.Column.DisplayText = 父親姓名
        ↓
Context.ShiftCheckField = 父親姓名
        ↓
既有 ShiftCheck / 驗證 / XML 邏輯（不變）
```

| 項目 | 結果 |
| --- | --- |
| 驗證欄下拉顯示 `家長1*`／`家長2*` | 是（邏輯驗證） |
| 識別欄下拉套用相同別名規則 | 是（邏輯驗證；家長欄位若 `Identifiable` 則適用） |
| `Context.IdentifyField` 儲存內部名稱 | 是 |
| `Context.ShiftCheckField` 儲存內部名稱 | 是 |
