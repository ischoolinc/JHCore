# 匯入家長1／家長2 調整紀錄

## 問題根因

匯入精靈已能將 Excel `家長1`／`家長2` 正規化為內部 `父親`／`母親`，且 UI 顯示也改用家長用語。但欄位選擇頁仍允許勾選 Excel 仍使用舊標題（`父親...`／`母親...`）的欄位，未強制要求來源檔改用新欄名。

## 修改檔案

| 檔案 | 說明 |
| --- | --- |
| `StudentExtendControls/Ribbon/StudentImportWizard.cs` | 新增家長欄位 helper、以 `SourceName` 驗證 Excel 標題；舊標題停用並顯示提示 |

未修改：

- `SheetColumn.Name`／`GroupName`／`SourceName` 儲存結構
- `BulkColumn.DisplayText`／`FullDisplayText`
- `ImportItem.InternalGroupName`／`InternalFieldName`
- `Context.AcceptColumns`／`SourceColumns`／`SelectedFields`／`BulkDescription`
- `BulkDescription.GenerateInsertRequest`／`GenerateUpdateRequest`
- `StudentBulkProcess.InsertImportStudent`／`UpdateImportStudent`
- XML 元素名稱、屬性與請求結構
- ListView 底色／選取相關調整

既有且沿用的相關機制（本次未再改動）：

- `SheetReader.NormalizeParentImportFieldNames()`：`家長1`／`家長2` → `父親`／`母親`
- `SheetColumn.SourceName`：保留 Excel 原始標題
- Designer 預設顯示：`家長1姓名`／`家長2姓名`

## 家長欄位對應規則

| Excel 欄位／UI 顯示 | 內部欄位／XML |
| --- | --- |
| `家長1...` | `父親...` |
| `家長2...` | `母親...` |

前綴對應（涵蓋現有與未來同前綴欄位）：

```text
父親... ↔ 家長1...
母親... ↔ 家長2...
```

範例：

| Excel／UI | Internal |
| --- | --- |
| `家長1姓名` | `父親姓名` |
| `家長1身分證號` | `父親身分證號` |
| `家長1國籍` | `父親國籍` |
| `家長1存歿` | `父親存歿` |
| `家長1其它資訊` | `父親其它資訊` |
| `家長2姓名` | `母親姓名` |
| `家長2身分證號` | `母親身分證號` |
| `家長2國籍` | `母親國籍` |
| `家長2存歿` | `母親存歿` |
| `家長2其它資訊` | `母親其它資訊` |

## Excel SourceName 驗證邏輯

在 `DisplayColumns(...)` 既有條件（可匯入欄、識別欄、驗證欄、群組完整性等）之後，對每個 `ImportItem` 呼叫 `TryValidateParentSourceNames`：

1. 以 `SheetColumn.Name`（內部名）判斷是否為父親／母親欄位
2. 以 `SheetColumn.SourceName`（Excel 原始標題）比對 `GetExpectedParentSourceName(Name)`
3. 必須完全相符（例如內部 `父親姓名` → Excel 必須為 `家長1姓名`）
4. 不符則：
   - `Enabled = false`（灰字、強制未勾選）
   - `ToolTipText = Excel 欄位「{實際}」請改為「{預期}」`

新增 helper：

- `IsFatherField`／`IsMotherField`
- `GetExpectedParentSourceName`
- `TryValidateParentSourceNames`
- `GetParentAliasDisplayText` 改為共用 `GetExpectedParentSourceName`（僅 UI，不改內部鍵）

## UI 啟用／停用與 Tooltip

| Excel 標題 | UI 顯示 | 可勾選 | Tooltip |
| --- | --- | --- | --- |
| `父親姓名` | `家長1姓名` | 否 | `Excel 欄位「父親姓名」請改為「家長1姓名」` |
| `家長1姓名` | `家長1姓名` | 是（其餘條件通過時） | （無此類提示） |
| `母親姓名` | `家長2姓名` | 否 | `Excel 欄位「母親姓名」請改為「家長2姓名」` |
| `家長2姓名` | `家長2姓名` | 是（其餘條件通過時） | （無此類提示） |

勾選後仍以內部名稱加入選取集合：

```csharp
Context.SelectedFields.Add(column.Name, column);
// 家長1姓名 → column.Name = 父親姓名
// 家長2姓名 → column.Name = 母親姓名
```

## 測試情境與結果

| # | 情境 | 預期 | 結果 |
| --- | --- | --- | --- |
| 1 | Excel 僅有 `父親姓名` | UI 顯示 `家長1姓名`；停用；不可勾選；Tooltip 要求改為 `家長1姓名` | 程式碼層通過 |
| 2 | Excel 有 `家長1姓名` | 可選；內部仍為 `父親姓名`；XML 不變 | 程式碼層通過（正規化＋驗證通過） |
| 3 | Excel 僅有 `母親姓名` | UI 顯示 `家長2姓名`；停用；Tooltip 要求改為 `家長2姓名` | 程式碼層通過 |
| 4 | Excel 有 `家長2姓名` | 可選；內部仍為 `母親姓名`；XML 不變 | 程式碼層通過 |
| 5 | 其他家長1舊欄（身分證號／國籍／存歿／其它資訊） | 舊標題停用；新標題可選且對應父親欄 | 前綴規則涵蓋，程式碼層通過 |
| 6 | 其他家長2舊／新欄 | 同上對應母親欄 | 前綴規則涵蓋，程式碼層通過 |
| 7 | Excel 無家長欄 | 不強迫新增；不從 Designer 預設產生可選家長項 | 欄位清單仍只來自來源欄位，行為不變 |
| 8 | XML 比對 | 父親／母親節點與 Insert／Update 請求相容 | 未修改 XML 產生路徑 |

> 實際開啟匯入精靈與匯入 Excel 的操作驗證，需於執行環境手動確認。

## 剩餘風險／後續

- 若群組欄位同時「成員不齊」且「使用舊標題」，Tooltip 會以家長欄名提示覆蓋群組缺欄提示；建議使用者先改 Excel 標題再開啟精靈。
- 建議以舊標題／新標題各一份 Excel，跑新增與更新匯入，確認畫面、勾選與產出 XML 皆符合預期。
