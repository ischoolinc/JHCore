# 匯入家長1／家長2 顯示問題調整紀錄

## 問題根因

先前匯入精靈的 UI 顯示邏輯不一致：

1. **預設欄位清單**（`StudentImportWizard.designer.cs`）仍寫死 `父親姓名`、`母親姓名`。
2. **`GetImportDisplayName()`** 僅在 Excel 原始標題已是 `家長1`／`家長2` 時才做顯示轉換；若來源仍使用 `父親`／`母親`，欄位選擇頁會繼續顯示舊用語。

識別欄／驗證欄下拉雖已透過 `GetParentAliasDisplayText()` 轉換，但欄位選擇 ListView 與預設清單未完整套用同一規則。

## 修改檔案

| 檔案 | 說明 |
| --- | --- |
| `StudentExtendControls/Ribbon/StudentImportWizard.designer.cs` | 預設 ListView 顯示文字改為 `家長1姓名`、`家長2姓名` |
| `StudentExtendControls/Ribbon/StudentImportWizard.cs` | `GetImportDisplayName()` 統一經 `GetParentAliasDisplayText()` 轉換群組與非群組顯示名稱 |

未修改：

- `SheetColumn.Name`／`GroupName`、`BulkColumn.DisplayText`／`FullDisplayText`
- `ImportItem.InternalGroupName`／`InternalFieldName`
- `Context.AcceptColumns`／`SourceColumns`／`SelectedFields`／`IdentifyField`／`ShiftCheckField`／`BulkDescription`
- `BulkDescription.GenerateInsertRequest`／`GenerateUpdateRequest`
- `StudentBulkProcess.InsertImportStudent`／`UpdateImportStudent`
- XML 元素名稱、屬性與請求結構

## 修改的方法與位置

### `StudentImportWizard.designer.cs`

- 預設欄位 ListViewItem：`父親姓名` → `家長1姓名`，`母親姓名` → `家長2姓名`（僅 UI 顯示文字）

### `StudentImportWizard.GetParentAliasDisplayText(string)`

顯示專用別名轉換（既有方法，用途擴及欄位清單）：

```csharp
if (displayText.StartsWith("父親"))
    return "家長1" + displayText.Substring("父親".Length);

if (displayText.StartsWith("母親"))
    return "家長2" + displayText.Substring("母親".Length);
```

僅當文字以 `父親`／`母親` 開頭才替換，因此 Excel 已是 `家長1姓名`／`家長2姓名` 時不會產生 `家長11姓名`／`家長22姓名`。

### `StudentImportWizard.GetImportDisplayName(SheetColumn)`

改為群組與非群組皆走同一顯示轉換：

```csharp
string displayText = column.IsGroupField
    ? column.GroupName
    : column.DisplayText;

return GetParentAliasDisplayText(displayText);
```

呼叫點：`GroupSheetColumn()` 建立 `ImportItem` 顯示文字時。

識別欄／驗證欄仍使用：

```csharp
string displayText = GetParentAliasDisplayText(each.DisplayText);
```

選取值寫回 `Context.IdentifyField`／`Context.ShiftCheckField` 時仍取 `BulkColumn.DisplayText`（內部名稱）。

| # | 情境 | 預期 | 結果 |

## 剩餘風險／後續

- 匯入精靈其他說明文字或訊息若仍寫死「父親／母親」，不在本次範圍；若發現請另行調整。
- 建議以一份舊標題 Excel、一份新標題 Excel 各跑一輪新增與更新匯入，確認畫面與 XML 皆符合預期。
