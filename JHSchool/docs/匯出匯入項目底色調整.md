# 匯出／匯入項目底色調整紀錄

## 問題描述

學生匯出與匯入精靈的欄位清單原本使用 `SmartSchool.Common.ListViewEX`。每個欄位項目背後持續顯示藍色底色。

## 先前錯誤診斷（V1）

V1 僅調整選取相關屬性：

- `HideSelection = true`
- `ItemSelectionChanged` 清除 `Selected`
- `BackColor = SystemColors.Window`

這些調整無法完全消除藍色底色，因為藍色並非僅來自 Windows 標準選取狀態。

## 確認根因（V2）

欄位清單控制項為：

`SmartSchool.Common.ListViewEX`

`ListViewEX` 使用 Office/DotNetBar 自訂項目繪製，即使項目未選取，仍可能以藍色背景繪出項目。

因此正確修正方式是將這兩個欄位清單改為標準 WinForms `ListView`，而非繼續在 `ListViewEX` 上調整選取／底色屬性。

## 修改檔案

| 檔案 | 說明 |
| --- | --- |
| `StudentExtendControls/Ribbon/StudentExportWizard.cs` | `ConfigureFieldListView()` 加上 `BorderStyle.FixedSingle` |
| `StudentExtendControls/Ribbon/StudentExportWizard.designer.cs` | `listView`：`ListViewEX` → `System.Windows.Forms.ListView`；移除 DotNetBar Border；改用 `BorderStyle.FixedSingle` |
| `StudentExtendControls/Ribbon/StudentImportWizard.cs` | `ConfigureFieldListView()` 加上 `BorderStyle.FixedSingle` |
| `StudentExtendControls/Ribbon/StudentImportWizard.designer.cs` | `lvSourceFieldList`：`ListViewEX` → `System.Windows.Forms.ListView`；移除 DotNetBar Border；改用 `BorderStyle.FixedSingle` |

## 控制項變更

| 精靈 | 控制項 | 變更前 | 變更後 |
| --- | --- | --- | --- |
| 匯出 | `listView` | `SmartSchool.Common.ListViewEX` | `System.Windows.Forms.ListView` |
| 匯入 | `lvSourceFieldList` | `SmartSchool.Common.ListViewEX` | `System.Windows.Forms.ListView` |

僅替換這兩個欄位清單；專案其他 `ListViewEX` 未動。

## 移除的 ListViewEX 專屬屬性

| 控制項 | 已移除 |
| --- | --- |
| `listView` | `Border.Class = "RibbonClientPanel"`、`Border.CornerType = Square` |
| `lvSourceFieldList` | `Border.Class = "ListViewBorder"`、`Border.CornerType = Square` |

## 新增的標準 BorderStyle

兩者皆設定：

- Designer：`BorderStyle = BorderStyle.FixedSingle`
- Runtime（`ConfigureFieldListView`）：`BorderStyle = BorderStyle.FixedSingle`

## 剩餘風險／後續

1. 需實際開啟匯出／匯入精靈做目視確認（藍色底色是否完全消失）。
2. 標準 `ListView` 外框樣式可能與原先 DotNetBar `ListViewEX` 邊框略有差異；若需完全一致可再微調外觀，但不應改回 `ListViewEX`。
3. 專案其他畫面若仍使用 `ListViewEX` 且出現類似底色問題，需個別評估，本次僅修正這兩個欄位清單。
